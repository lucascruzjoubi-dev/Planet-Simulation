# Planet-Simulation
A short simulation of orbiting planets around the sun.


The simulation contains the sun, mercury the earth and the moon 🌑

It has real aspects of physics, like the usage of the AU(Astronomical unit), physics formulas like the universal gravitation formula, and other concepts.

It has also usage of classes for creation of planets and the moon, and the usage of pygame, the python libray, that was used for creating the imaging of the project. 

The project is still very inferior to what i wanted it to be, but, is still very solid.

This still leaves room for improvement.
